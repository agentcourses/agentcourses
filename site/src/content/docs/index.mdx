<p class="ac-thesis">Agent skills teach your agent. Agent courses teach you, through your agent.</p>

A course is a folder of Markdown files. The author writes lessons, checks and rubrics. Any agent that supports the format can then tutor a learner through it. It builds with them, runs the checks and asks them to explain what they made.

The agent may do the typing. The learner makes the decisions, and only evidence counts as progress.

<Aside type="caution" title="Beta">
Agent Courses is at version 0.1. The format may change in breaking ways before 1.0. Every change is listed in the [changelog](/changelog/).
</Aside>

## Why a course format

An agent in your project can build things faster than you can follow. That helps you ship. It does not always help you learn.

A course gives the agent a plan for teaching instead. It says what you should be able to do by the end. It marks the decisions that are yours to make. And it says how to tell that you have learned it: checks that look at your project, and an explanation in your own words.

The format is open. An author writes a course once, and any agent that supports the format can teach it.

## How a lesson runs

1. **Goal.** The tutor says what the learner will be able to do.
2. **Build together.** The tutor and the learner make it in the learner's project. The tutor shows each change and says why.
3. **Calls.** Decisions that belong to the learner are put to them. The tutor may recommend an answer, but never decides.
4. **Checks.** Small scripts look at the project and say pass or fail.
5. **Explain back.** The learner explains what they made, in their own words. The tutor judges the answer against a private rubric.

## Skills and courses

An [agent skill](https://agentskills.io) is a folder of instructions that gives your agent a new ability. When it runs, the agent does the task.

An agent course is a folder that gives *you* a new ability. When it runs, the agent teaches you to do the task. You finish by showing that your work passes its checks and explaining how it works.

Both are folders with one Markdown entry file: `SKILL.md` for a skill, `COURSE.md` for a course.
