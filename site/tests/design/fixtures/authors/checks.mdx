## A sample exit-code table

The table below is deliberately wide. On a phone it scrolls inside its own frame while the page stays still.

| Exit code | Sample meaning | Sample reader action | Sample identifier |
|---|---|---|---|
| `0` | The sample check passed. | Continue to the next sample step. | `sample-check-passed-with-a-long-identifier` |
| `1` | The sample check failed. | Read the sample message and try again. | `sample-check-failed-with-a-long-identifier` |
| `2` | The sample check could not run. | Report the sample problem to its author. | `sample-check-unavailable-with-a-long-identifier` |

## A sample check script

```sh title="checks/sample-check.sh"
#!/bin/sh
# A fixed sample script. It shows a long line scrolling inside the dark panel without moving the page.
test -f README.md || { echo "Sample failure: README.md is missing from the sample project directory, so this check cannot continue"; exit 1; }
echo "Sample check passed"
```

An unbroken identifier also wraps safely in prose: `sample.identifier.that.is.deliberately.long.enough.to.need.wrapping.on.a.phone`.
