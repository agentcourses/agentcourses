Start with a small course that teaches one useful change. Write what the learner will build and explain, then check the structure. A valid folder still needs thoughtful teaching.

## Sample steps

<Steps>

1. ### Create a sample folder

   ```sh
   mkdir sample-course
   ```

2. ### Write a sample file

   ```md title="sample-course/COURSE.md"
   # Sample course

   Sample text for a course file.
   ```

3. ### Check the sample

   ```sh
   ls sample-course
   ```

</Steps>
